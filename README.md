# EV Analysis Dashboard – Tableau

## 📊 Project Overview

This project presents an interactive Tableau dashboard developed to analyze Electric Vehicle (EV) data and identify important trends and patterns across vehicle types, manufacturers, counties, vehicle years, and geographic locations.

## 🎯 Project Objective

The objective of this project is to explore EV adoption patterns and understand the distribution of electric vehicles across different manufacturers, counties, vehicle types, and years.

## 🛠️ Tools Used

- Tableau
- Data Visualization
- Data Analysis

## 📌 Dashboard Preview

![EV Analysis Dashboard](EV-Dashboard.png)

## 📈 Key Analysis

The dashboard provides analysis of:

- Electric vehicle types
- EV manufacturers and makes
- Top 10 counties by number of vehicles
- Vehicle year trends
- Geographic distribution of EVs
- EV distribution by postcode

## 🔎 Interactive Features

- Vehicle Type selection
- Car Make filter
- Interactive map
- County-level analysis
- Vehicle year analysis
- Click-to-show-model interaction

## 💡 Key Insights

- Tesla has the highest number of vehicles among the available manufacturers.
- King County has the highest number of EVs among the counties shown.
- EV registrations vary considerably across counties.
- Vehicle registrations show changes across different model years.
- EVs are geographically concentrated in specific areas of Washington.

## 📍 Geographic Analysis

The dashboard uses maps to visualize the geographic distribution of EVs across Washington State and identify areas with higher concentrations of electric vehicles.
